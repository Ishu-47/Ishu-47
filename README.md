- Built and deployed a full-stack social media platform with authentication, social interactions, real-time messaging, notifications and media management.
- Implemented Redis caching and Pub/Sub, feed and explore functionality, infinite scrolling and notification workflows.
- Developed real-time communication using WebSocket/STOMP and secured REST APIs using JWT authentication.

### 🔹 CollabCode – Real-Time Collaborative Coding Platform

**Java | Spring Boot | React | PostgreSQL | WebSockets | Docker**

- Developed a collaborative coding platform with room management, authentication and real-time code synchronization.
- Implemented server-side code execution using Docker.

### 🔹 Event Registration System

**Java | Spring Boot | Spring Security | PostgreSQL | REST APIs**

- Built an event registration platform with Organizer and Check-in Staff roles using JWT authentication and Role-Based Access Control (RBAC).

- Developed session-staff assignment and CSV bulk import/export workflows.
